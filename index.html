001
Active · Final Year
Linguix-NG — Intelligent Normalization Middleware

More than 75 million Nigerians speak Pidgin every day but the enterprise platforms they rely on for banking and healthcare are written for formal Western English. That mismatch means real people get locked out of real services. Linguix-NG sits between the user and the API and translates naturally spoken Nigerian language into standard English in real time, with zero changes needed on the backend side.

PythonNLPTransformersHuggingFaceNigerian PidginREST API
  • Curated a parallel corpus pairing Nigerian Pidgin and Yoruba-influenced English with formal equivalents, a dataset that did not exist before this project.
  • Hybrid architecture: rule-based lexical mapping handles common substitutions fast, while a Transformer model catches the nuanced cases.
  • Middleware deployment means it plugs into any FinTech or HealthTech API without touching the downstream codebase.
  • Contributing open benchmarks for Nigerian language normalisation to advance African NLP research beyond this project.
